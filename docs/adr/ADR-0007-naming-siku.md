# ADR-0007：项目命名——siku（四库）

- **状态**：已接受
- **日期**：2026-09-17

## 决策

项目名 / 目录名 / 包名 / CLI 名统一为 **`siku`**（四库）。

命名故事一句话：《四库全书》= 历史上最大规模的"汇总天下文献 → 自动编目（总目提要）→
结构化检索"工程，与本项目"丢入全部文档 → 自动图谱与 wiki → 自然语言检索"完全同构。
"总目提要"即本项目 wiki 功能的文化原型。

## 实证过程

按判据（短小可键入、有故事、注册渠道干净、相邻领域无知名同名）对七个候选实测
pypi / npm / Homebrew 占用：

| 候选 | pypi | npm | 结论 |
|---|---|---|---|
| **siku** | 空闲 | 空闲 | **采用** |
| summa | 占用 | 占用 | 淘汰（且有同名 NLP 摘要库） |
| mycelium | 占用 | 占用 | 淘汰 |
| rhizome | 占用 | 占用 | 淘汰 |
| engram | 占用 | 占用 | 淘汰 |
| trove | 占用 | 占用 | 淘汰（且澳洲国家档案馆 Trove 同域撞名） |

## 被否选项（语义层）

- **描述性名**（notebase/kb-app 类）：平庸不可注册，故事讲不出；
- **langhuan（嫏嬛）**：天堂图书馆意象极美，但 8 字母 + 全球发音门槛，实用性输给 siku；
- **engram / rhizome**：隐喻贴切但已被占。

## 代价与风险

- 德国 SIKU 合金玩具车品牌同名——商品类别无关，开源软件无碍；商业化时需做商标清查；
- siku.cn 为房产网站，非开发者语境，无混淆。

## 复核信号

若未来商业化需要商标注册，重开本 ADR 做全类目清查；开源阶段不作变更（改名成本随
用户量指数增长，越晚越动不了）。
