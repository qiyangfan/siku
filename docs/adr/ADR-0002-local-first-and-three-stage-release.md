# ADR-0002：本地优先与三阶段发布

- **状态**：已接受
- **日期**：2026-09-17

## 背景

产品形态三选一：SaaS（云端多租户）、裸本地服务（pip/Docker 自运维）、本地桌面应用。
约束：目标场景是"用户把全部个人文档丢进来"——这是人最不愿意交出的数据；开发者为单人；
云端轻量问答市场已被 NotebookLM 占死。

## 决策

**本地优先；终态 = Tauri 桌面壳；开发期 = localhost WebUI。** 三阶段推进：

| 阶段 | 形态 | 受众 | 成本 |
|---|---|---|---|
| 一（当前） | `uv tool install` + localhost WebUI + CLI | 开发者/早期用户 | 零 |
| 二 | Tauri 壳（不签名），GitHub Releases + Homebrew | 尝鲜用户 | ≈0 |
| 三 | 签名 + 自动更新 | 全量用户 | Apple $99/年 + Azure Trusted Signing ~$10/月 |

配套红线：**UI ↔ 内核只经 localhost HTTP API**，业务逻辑禁止进入前端或壳——内核对 UI
形态零假设，三阶段切换才不需要重写。

## 理由（账本）

| 维度 | SaaS | 本地桌面 |
|---|---|---|
| 信任 | 全部个人文档上传服务器——最不愿意交出的数据 | 语料不动，唯一说得通的信任方案 |
| 成本 | 每用户推理+存储费，用户量即负债 | 用户自带 key，成本归零 |
| 运维 | 多租户/鉴权/备份/合规，单人背不动 | 打包+更新，一次性脏活 |
| 竞争位 | NotebookLM 占死轻量云端问答 | 本地+图谱+wiki 是确认过的空白 |

## 被否选项

- **SaaS**：上表三行全输；且信任一行说明本地优先不只是省钱，是产品成立的前提；
- **Docker/pip 形态面向大众**：门槛阶梯是 双击安装 ≪ 命令行 < Docker；裸 WebUI 不是
  更便宜的等效方案，而是换受众（从"所有人"换成"会用命令行的人"）。阶段一接受这个
  受众收窄，用阶段二/三赎回；
- **v1 就做协作/同步**：多设备协作是独立产品形态，vault 本来就是文件夹，将来做"只读
  发布/文件同步"伴侣功能即可，主模式永远本地。

## 隐私诚实条款

本地 ≠ 全离线：图谱抽取与问答调 LLM API 时文本片段瞬时出户。与 SaaS 的本质区别是
**无服务器持久化语料、无账号、无锁定**。三配套：BYO key、Ollama 全离线降级通道、
隐私说明写清哪一步数据会出门。这个故事讲好了是卖点，藏着掖着是雷。

## 代价与风险

- 阶段二打包 Python sidecar 是最脏的工程活（已明知，排期偿还而非现在）；
- 签名年费与三平台出包是"发布日"成本，不阻塞开发。

## 复核信号

出现强多人协作需求 → 开独立产品线评估，不改单机内核契约；阶段二尝鲜用户因安装门槛
流失显著 → 提前阶段三签名投入。
