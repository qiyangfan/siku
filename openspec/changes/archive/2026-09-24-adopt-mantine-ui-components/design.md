# 设计：Mantine 通用 UI 控件迁移

## 决议

### 决议 #1：唯一通用组件库——Mantine Core 9.x

将 `@mantine/core` 与 `@mantine/hooks` 加入 `ui/` 的生产依赖，保持版本一致并锁定于 npm lockfile。应用入口导入 Mantine Core 全局样式，并由单一 `MantineProvider` 提供主题。首期采用官方默认 CSS 样式系统，不为通用控件建立自有包装库。

### 决议 #2：库组件与产品专属呈现的边界

按钮、表单、导航、布局、弹窗与状态反馈使用 Mantine 现成组件。表单业务校验、API 状态处理和领域文案仍留在现有视图/服务中，库组件负责呈现与通用交互。

Sigma.js + graphology 继续负责图谱布局与画布；`ui/src/markdown.ts` 继续负责 Markdown 解析和净化。只迁移这两类视图的周边控件，不重写画布或安全渲染器。

### 决议 #3：渐进迁移与行为冻结

先接入 Provider 和主题，再按 App 壳、设置、资料库、浏览/wiki、图谱控件的顺序迁移。每个视图保留当前加载、空态、成功、失败和禁用语义；迁移只替换控件实现，不改变 API 请求与业务流程。

删除通用 CSS 规则前，检查引用范围。Sigma 画布尺寸、wiki/Markdown 正文排版、图形可视化样式与视图专属布局继续由产品 CSS 管理。

### 决议 #4：测试与无障碍

测试共用带 MantineProvider 的渲染包装器。交互测试优先通过可访问名称、角色和用户事件验证行为，不依赖 Mantine 内部 class 名。交付前检查键盘导航、焦点可见性、标签关联、错误提示和窄窗口布局。

### 规划闸门 A：信息架构、设计 token 与控件映射

- **核心任务**：让用户针对本地知识发起有来源的问答；用户进入应用后先看到问题输入区和本地服务连接状态。设置、资料管理、浏览、图谱和 wiki 是支持任务，沿用现有导航层级。
- **Token 单一来源**：从现有 `ui/src/styles.css` 迁移当前 token 到 `ui/design-system/MASTER.md`，并映射到 Mantine theme：主色 `--color-accent`、中性色 `--color-ink` / `--color-canvas` / `--color-surface`、语义成功/警告/危险色；字阶沿用 display/body/caption；间距维持 4px 基线及其倍数；保留现有圆角与卡片阴影。首期不改变视觉方向，组件样式不新增 token 外裸 hex 或裸 px。
- **控件映射**：

| 数据/操作 | 控件 | 交互约束 |
|---|---|---|
| 自然语言问题 | Mantine `Textarea` | 多行输入；保留现有 Enter/快捷键提交语义 |
| API endpoint、模型名、目录路径等短文本 | Mantine `TextInput` | 明确标签；超长值不撑破容器 |
| API 凭证 | Mantine `PasswordInput` | 默认遮蔽；沿用现有保存/校验流程 |
| 扫描间隔等数值 | Mantine `NumberInput` | 限定有效范围并保留单位说明 |
| 开关类设置 | Mantine `Switch` | 呈现即时生效/需保存语义 |
| 文件选择、视图切换 | Mantine `FileInput` / `Tabs` | 标签和选中状态可被辅助技术读取 |
| 操作状态与破坏性确认 | Mantine `Alert`、`Loader`、`Modal` | 空态、加载、失败均有落点；删除/清理使用标准确认框 |

- **方案自查**：知识问答的主任务、资料流入路径和“浏览—图谱—wiki”支撑关系来自 Siku 产品边界；仅控件皮肤与通用交互交给组件库，不借迁移重排信息架构或添加装饰性视觉。

## 实施风险

- 默认样式可能覆盖现有全局 CSS；以视图为单位迁移，禁止一次性删除未盘点的样式。
- Mantine Provider 会成为 UI 根级运行环境要求；所有独立组件测试必须使用统一包装器。
- 若 Mantine 提供的通用组件不足以表达特定领域状态，可用 Mantine 原语组合视图级组件；不得复制一套通用组件实现。
- UI 闸门 B 需实际填入至少 30 字符的资料/来源名，检查空态/加载/失败态与 375px 下无横向滚动；验证正文对比度至少 4.5:1、交互目标至少 44×44px、键盘焦点可见及 reduced-motion。金额类输入不适用于本产品；并核对各视图主按钮唯一、同类动作文案/位置/样式一致。
