# 提案：根据本地知识推荐提问

## Why

问答首页目前使用固定的“项目边界”示例，假设用户导入了特定内容，换一份语料就会显得不相关。知识库已有笔记章节和 wiki 社区实体，可以据此给用户具体、可直接编辑的问题入口。

## What Changes

- 问答页进入且本地服务可用时，读取现有笔记和 wiki HTTP API，为当前语料生成最多三条提问建议。
- 建议由笔记标题/章节和 wiki 社区实体组合成，不为建议额外调用模型，也不改服务端 API。
- 点击建议只预填并聚焦问题输入框，不自动提交；用户可以编辑后再发送。
- 空语料时说明导入资料或生成 wiki 后会出现建议；读取失败时保留手动提问能力，不展示虚构内容。
- 导入的 Skill Markdown 按普通笔记章节处理，不要求应用读取未导入的本地 skill 文件。

## 受影响决策

- **ADR-0001**：推荐信息只经 localhost HTTP API 读取，前端不直接访问 vault 或派生存储。
- **ADR-0011**：问题建议使用 Mantine 通用按钮与现有主题 token，保持桌面和移动端样式一致。

## 与项目路线的关系

该 change 细化问答首页的首次使用体验，不改变问答、检索、索引或知识生成契约。

## 不做清单（Non-goals）

- 不调用 LLM 生成、排序或改写推荐问题。
- 不新增 HTTP API，不直接读取 vault、SQLite、LanceDB、parquet 或 wiki 文件。
- 不推荐未导入的文档或尚未进入知识库的个人 skill 文件。
- 不保存用户偏好、推荐历史或最近使用问题。
- 不自动提交推荐问题，不改变问答请求和引用流程。

## 规格处理

新增 `web-ui` 的内容驱动提问建议要求；归档时将 delta 同步到主规格。
