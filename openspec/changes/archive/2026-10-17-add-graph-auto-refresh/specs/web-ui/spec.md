## MODIFIED Requirements

### Requirement: 提供桌面资料库视图

界面 SHALL 提供资料库视图：来源清单（名称、摄取与索引状态徽标，含原件缺失与已
替代徽标，喂养条目展示上游路径）、导入入口、摄取进度反馈与全量重建入口（先经确认
对话框）。导入入口 SHALL 呈现为文件选择控件形态：点击可打开系统文件选择器，且
支持把文件拖入投放；视图 SHALL 另提供来源目录管理区（添加、启停、移除与最后扫描
时间展示）、立即扫描入口（含全量校验选项）、自动扫描间隔设置、图谱自动刷新开关
（缺省关闭，附中文说明：仅在已构建图谱时增量维护、不自动创建、更换模型或 prompt
后需显式更新）与确认式清理入口（展示待清理数量）。物理删除类清理入口 SHALL 以
危险配色标识并与普通操作区分。上述操作 SHALL 全部经 localhost API 完成并展示
中文反馈；任务结果区的派生维护通知（如图谱自动刷新的计数、跳过原因或失败事实）
SHALL 以中文展示。界面 SHALL NOT 直接读写 vault 文件内容，SHALL NOT 直接读写
来源目录。视图 SHALL 遵循既有可访问性要求：主要操作键盘可达，来源区、清单与进度
在窄窗口可读。

#### Scenario: 导入并跟踪进度

- **GIVEN** 用户在资料库视图选择本地文件导入
- **WHEN** 摄取任务执行
- **THEN** 界面展示进度与逐文件结果（成功/失败中文说明），结束后刷新清单状态

#### Scenario: 拖拽文件投放

- **GIVEN** 用户把若干本地文档拖到导入区上方
- **WHEN** 松开投放
- **THEN** 界面以与点击选择相同的路径发起摄取；拖拽悬停时投放区有可见高亮反馈

#### Scenario: 空状态引导

- **GIVEN** 桌面 vault 为空
- **WHEN** 用户打开资料库视图
- **THEN** 界面展示导入引导与支持格式说明，不展示空白列表

#### Scenario: 重建确认

- **GIVEN** 用户点击全量重建索引
- **WHEN** 确认对话框被确认或取消
- **THEN** 仅确认后发起重建并展示进度反馈，取消时不产生任何请求

#### Scenario: 管理来源目录并触发扫描

- **GIVEN** 用户在来源目录区添加了一个本地目录
- **WHEN** 扫描执行
- **THEN** 界面展示扫描进度与中文结果反馈，清单出现新文档及其上游路径，来源区
  展示最后扫描时间

#### Scenario: 清理已标记文档

- **GIVEN** 清单存在原件缺失或已替代徽标的文档
- **WHEN** 用户点击清理
- **THEN** 界面先展示待清理数量并要求确认，仅确认后发起清理并展示结果反馈，
  取消时不产生任何请求

#### Scenario: 图谱自动刷新开关与通知

- **GIVEN** 用户在资料库视图看到自动扫描间隔设置
- **WHEN** 用户切换图谱自动刷新开关
- **THEN** 开关旁展示其中文说明（缺省关闭、仅维护已构建图谱、模型或 prompt 变更
  后需显式更新），切换经 API 持久化并免刷新生效；任务结束后通知区展示刷新计数、
  跳过原因或失败事实
